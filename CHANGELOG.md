## [0.1.0] - 2026-01-10

### Highlights

- Initial release with Google Drive and Google Cloud Storage backends for OmniStorage

### Added

- Google Drive backend (`backend/drive`) with full `ExtendedBackend` implementation
- Google Cloud Storage backend (`backend/gcs`) with full `ExtendedBackend` implementation
- Service account authentication for both backends
- OAuth2 user credentials support for Google Drive
- Application Default Credentials support for GCS
- Server-side copy for both backends
- Server-side move for Google Drive, copy+delete for GCS
- Path-to-ID resolution with caching for Google Drive
- Shared Drive (Team Drive) support for Google Drive
- MD5 hash support for both backends
- CRC32C hash support for GCS
- Range read support for both backends
- Resumable uploads with configurable chunk size
- Backend registry integration (`gdrive` and `gcs` names)
- Configuration from environment variables
- Configuration from string maps for flexibility

### Documentation

- README.md with usage examples and configuration reference
- GoDoc comments on all public APIs

### Tests

- Unit tests for configuration parsing
- Unit tests for backend operations

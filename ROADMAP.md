# omnistorage-google Roadmap

This roadmap documents planned and completed features for this project.

The format is based on and generated by [Structured Roadmap](https://github.com/grokify/structured-roadmap), which provides a machine-readable JSON intermediate representation with deterministic Markdown generation.

## Overview

This roadmap tracks the development of Google Cloud backends for OmniStorage.

---

## Other

### [x] Google Cloud Storage Backend

Full ExtendedBackend implementation for GCS

**Version:** 0.1.0 (2026-01-10)

### [x] Google Drive Backend

Full ExtendedBackend implementation for Google Drive API

**Version:** 0.1.0 (2026-01-10)

### [ ] Batch Operations for GCS

Batch copy, move, and delete operations using GCS batch API

**Target:** 0.2.0

### [x] OAuth2 User Credentials

Support for OAuth2 user authentication in Drive backend

**Version:** 0.1.0 (2026-01-10)

### [x] Shared Drive Support

Team Drive / Shared Drive support for Google Drive

**Version:** 0.1.0 (2026-01-10)

### [ ] Streaming Uploads for Drive

Stream large files directly to Drive without buffering in memory

**Target:** 0.2.0

- [ ] Implement resumable upload with streaming
- [ ] Add progress callbacks

### [ ] Firebase Storage Backend

Backend for Firebase Cloud Storage (uses GCS under the hood)

### [ ] Progress Callbacks

Upload/download progress callbacks for large file transfers

**Target:** 0.2.0

### [ ] Signed URL Generation

Generate pre-signed URLs for temporary access

**Target:** 0.3.0

### [ ] Cloud Filestore Backend

Backend for Google Cloud Filestore NFS

### [ ] GCS Lifecycle Policies

Support for reading/managing GCS object lifecycle policies
